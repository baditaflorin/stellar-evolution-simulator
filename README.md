# Stellar Evolution Simulator

Live site: https://baditaflorin.github.io/stellar-evolution-simulator/

Browser-based stellar lifecycle simulator using Pyodide, Plotly, and a MESA-inspired model subset.

This repository is being scaffolded as a static GitHub Pages application.

## Quickstart

```sh
make install
make dev
make test
make build
make smoke
```
